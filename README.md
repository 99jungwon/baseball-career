# 더 라스트 이닝 — v0.6

18세 고교 선수부터 은퇴까지, 훈련과 선택으로 기록을 쌓는 타자 육성 데모. 이어서 작업할 때는 **[docs/NEXT_SESSION.md](docs/NEXT_SESSION.md)** 를 먼저 읽으세요. 상세 인계는 docs/HANDOFF.md에 있습니다. 공개 배포판: https://99jungwon.github.io/baseball-career/

## 실행

이 폴더에서 `node server.js`, 브라우저에서 http://localhost:4173/ . 외부 패키지 설치나 빌드는 필요 없습니다.

검증: `node tests/engine.test.js`, `node tests/league.test.js`.

## 현재 기능

- 모바일 세로 배치와 하단 메뉴, 큰 글씨와 진한 설명 색상.
- 이름/등번호/투타/9개 타자 포지션/희망 구단 설정.
- 고교→대학·드래프트·미국 아마추어 계약, 마이너/MLB, KBO 포스팅 및 복귀.
- 조건별 조언과 선택, 코스·주루 판단 미니게임, 훈련·휴식, 장기 커리어와 은퇴.
- KBO 10개 구단명, 내 선수를 포함한 가상 타자90명, 가상128경기 시즌.
- 시즌 기록실: 팀 순위, 개인 타격 순위, 정규시즌 우승, 포스트시즌·한국시리즈, 타격왕·홈런왕·MVP·신인상·야수 골든글러브.
- 개인 기록실: 누적 기록, 직전 동일 리그와 비교, 최근12시즌 성장 그래프, 시즌별 수상과 팀 결과.
- 은퇴 선수 보관함, 9명 타순·수비 배치, 중복 배치 방지, 라인업 저장.

## 저장

진행 커리어와 은퇴 보관함/라인업은 별도 브라우저 저장입니다. 같은 브라우저·주소에서 이어집니다. localhost와127.0.0.1, 포트가 달라지면 서로 다른 저장입니다.

새 커리어를 만들어도 보관 선수와 라인업은 남습니다. 은퇴한 현재 선수는 새 선수 시작 전에 보관 저장하며, 저장 실패 시 전환을 중단합니다. 현역 저장은 새 선수 시작으로 교체되므로 먼저 기록 JSON을 내려받으세요. 내보내기는 현재 커리어와 보관함을 포함하며 가져오기는 아직 없습니다.

기존 현재 구단은 서울 그린웨이브→LG, 부산 블루하버→롯데, 수원 레드폭스→KT로 대응합니다. 과거 완료된 시즌은 기존 기록을 유지합니다. 기존 진행 시즌의 상대 기록은 내 기록·팀 승패를 보존해 생성하며 화면에 안내합니다.

## 데모 범위

실제 구단명만 사용하며 선수·성적·진학·계약·시상·일정은 게임용입니다. 공식 KBO 규정이나 실제 선수 로스터를 재현하지 않습니다. 리그 기록실은 KBO 타자 전용이며 투수/미국/학교 전체 리그는 없습니다. NPC 독립 커리어, 라인업 대전, 로그인, 서버 저장과 배포는 미구현입니다. 통산은 고교·대학·마이너·프로를 모두 포함합니다.

상세 가상 시상·포스트시즌 규칙과 검증은 docs/HANDOFF.md, docs/VERIFICATION.md에 있습니다. 선수 DNA, 아이콘, 로그인·DB·배포는 후속 작업으로 기록했습니다.

구단명 참고: [KBO 구단 소개](https://www.koreabaseball.com/Kbo/League/TeamInfo.aspx).
