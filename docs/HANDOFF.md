## 사용자와 합의한 방향

한국어로 편하게 대화한다. 사용자는 계획 제안만 듣기보다 실제 동작하는 데모를 원한다.

- 야구선수 육성 게임. 핵심은 훈련과 시즌 중 선택. 참고작 https://slbcareer.com/ 는 비시즌 결정 중심이라 시즌 중 개입이 부족하다는 피드백.
- 한 시즌 체험이 아니라 선수 은퇴까지 플레이하고 마지막에 전체 커리어를 평가·요약한다.
- 38세 같은 고정 은퇴 금지. 최형우처럼 40세 이후 정상급도 가능해야 한다. 은퇴는 직접 결정하지만 소속 구단 거부 + 다른 구단 제안 없음이면 계약 불발 은퇴.
- 고교 시작, 대학 진학/국내 드래프트/성적에 따른 미국 직행, 팀 선택 요소. 고교 미국 직행은 실제 용어상 포스팅이 아니라 아마추어 계약으로 표시했다.
- 타이밍 바를 그대로 따라한 느낌과 일정한 타이밍을 싫어함. 자체 코스 판단·주루 판단 미니게임으로 교체.
- 과도한 훈련 체력 소모를 낮추고 경기 패널티·결장 위험·훈련 후 예상 체력을 명시.
- 매번 동일한 선택지 대신 최근 성적·체력에 맞는 감독/코치/주장/트레이너 조언. 로직만으로 뻔해지지 않게 조건 후보 + 가중 랜덤 + 반복 제한 + 조용한 날. 위험한 피로는 항상 경고.
- 생성 시 이름/등번호/주손 설정. 좌우 타격 방향도 분리 구현.
- 마지막 추가 요구: 마이너/메이저에서 KBO 복귀, KBO 입단 후 포스팅으로 미국 진출. 두 방향 모두 구현했다.
- 지금까지 반영한 코드와 새 대화에 필요한 내용을 저장해 달라는 요청. 새 채팅 자체를 자동 생성하지는 않았다.

## 2026-10-08 추가 합의 — 데모 우선, 이후 작업

### 사용자가 확인한 핵심 방향
- 선수 육성의 재미는 기록의 성장과 누적, 시즌별 변화, 수상, 팀 우승에 미치는 영향을 확인하는 데 있다. 기능 추가와 화면 설계의 우선 기준으로 삼는다.
- 모바일 세로 화면을 선호한다. 작은 글씨와 밝은 배경 위 연한 초록 글씨의 가독성을 개선한다.
- 은퇴한 선수를 보관하고, 내가 키운 선수들로 나만의 라인업을 구성하고 싶다.
- 국내 팀은 KBO 10개 구단을 사용한다. 시즌 기록실에서 팀 순위·우승·개인 순위·타격왕·골든글러브 등을 확인하고 싶다.
- 우선 데모를 만들고 재미와 흐름을 검증한다. 로그인·DB·서버·공개 배포는 이후 단계에서 진행한다.
- 아이콘 등 게임 분위기를 살리는 시각 요소를 더하는 작업도 후속 할 일로 기록한다. 구체적인 아이콘 스타일과 범위는 아직 정하지 않았다.

### 나중에 할 일 (아직 구현·배포하지 않음)
1. **게임 시각 요소**: 훈련·능력치·메뉴 아이콘, 선수 카드와 수상 표현 등을 검토. 스타일은 추후 결정한다.
2. **공개 테스트 배포**: GitHub에 프로젝트 코드 보관 후 정적 호스팅 연결. 이 대화에서는 배포를 실행하지 않는다.
3. **계정 저장**: 로그인, 사용자별 진행 커리어·은퇴 선수 보관함·라인업의 클라우드 저장 및 다른 기기에서 이어하기.
4. **저장 이전과 복구**: 브라우저 저장을 계정으로 이전, 백업 가져오기, 여러 기기에서 수정할 때 충돌 처리.
5. **경쟁 기능을 추가할 경우**: 경기 계산·보상·공식 랭킹 검증을 서버에서 수행. 로컬 계산 결과만 신뢰하는 방식을 그대로 경쟁 모드에 쓰지 않는다.

### 기술 제안 (사용자의 최종 서비스 선택 아님)
- 현재 HTML/CSS/JS 데모: GitHub Pages로 정적 배포 가능. GitHub는 코드 보관, Pages는 웹 호스팅의 역할.
- 로그인·DB·데이터 API: Supabase Auth + Postgres + 사용자별 접근 규칙(RLS)을 제안했다. 별도 상시 서버를 직접 운영하지 않아도 계정 저장을 구성할 수 있다.
- Cloudflare Pages 등 정적 호스팅도 대안이다. 서비스 가입·비용·구체적인 배포 방식은 아직 확정하지 않았다.

## 후속 아이디어 — 선수 DNA 불러오기 (사용자 제안, 아직 미구현)

사용자는 NBA 2K의 선수 DNA 기능과 유사하게, 레전드의 신인 시절 능력과 잠재력을 참고한 나만의 선수를 현재 시즌의 팀에서 육성하는 방식을 제안했다.

- 예시: 2026 KIA에서 신인 선동열의 능력·잠재력을 가진 나만의 선수, 2026 두산 3루에서 신인 김동주의 능력·잠재력을 가진 나만의 선수.
- 기본 리그를 현 KBO 선수들의 시즌 기록에 기반해 구성하는 아이디어도 언급했다. 현재 데모는 가상 선수·가상 성적이며 실제 선수 기반 로스터는 구현되지 않았다.
- 사용자가 중요하게 여기는 재미: 같은 출발점에서도 훈련·선택에 따라 달라지는 기록, 누적, 수상과 팀 성과, 레전드 또는 이전 육성 선수와의 커리어 비교.

### 설계 제안 (최종 확정 아님)
1. DNA에는 초기 능력, 포지션·투타 유형, 능력별 잠재력과 성장 성향을 담는다. 전성기 완성 능력이나 실제 선수의 미래 기록을 그대로 보장하지 않는다.
2. 참고 시즌의 관측 기록과 게임용 환산 능력·추정 잠재력을 구분한다. 신인 기록만으로 잠재력이 객관적으로 정해진다고 표현하지 않는다.
3. DNA 선택 → 내 이름·등번호·시작 팀 설정 → 육성 → 시즌·통산 기록 비교 → 은퇴 보관함의 흐름을 검토한다.
4. 타자 DNA부터 시범 구현. 투수 DNA는 투수 육성, 구종·제구·구위, 선발/불펜, 투구 기록·시상 체계가 필요하다. 현재 데모는 타자 전용이다.
5. DNA와 리그 로스터를 분리한다. 예: 2026 로스터 + 신인 레전드 DNA의 조합. 현재 고교 시작과 프로 구단 직행 시작을 어떻게 제공할지도 추후 결정한다.
6. 파일로 DNA 내보내기/불러오기, 이후 공유 기능은 버전·값 검증과 출처 메타데이터를 포함하는 방식으로 검토한다.
7. 실명·이미지·구단 브랜드·실제 데이터의 공개 서비스 사용 범위는 배포 전에 별도 확인한다. DNA 형식이라는 이유만으로 권리 문제를 해결했다고 가정하지 않는다.

데모의 기본 육성·기록·보관 흐름을 먼저 검증하고, 위 내용은 후속 기획으로 유지한다.

## v0.5 작업 — 잠재력·밸런스 (2026-10-08)

### 사용자 합의
- 잠재력은 랜덤이어야 리세(다시 뽑기) 재미가 생긴다.
- 잠재력이 낮아도 직접 육성해서 골든글러브·우승에 도전하는 유저가 꺾이지 않도록, 훈련으로 따라갈 수 있는 보정이 필요하다.

### 계기 (플레이테스트)
v0.4는 자동 진행 180커리어 전원이 46~48세 은퇴, 통산 약 3,700안타, 수상 48개였다. 능력치가 25~30세에 모두 100이 되고, 47세에도 112경기 출전·계약이 이어졌다.

### 구현 (engine.js)
- `potential`: 능력별 숨은 한계(현재+6~99), 별도 RNG 스트림(같은 시드는 같은 잠재력, 커리어 RNG 불변). `longevity`(-2~+3)로 노화 시작을 개인별로 이동.
- 성장 배율 `growthFactor`: 한계까지 15이상 남음 1 / 6이상 .7 / 그 이하 .45. 한계 돌파 구간은 .25이며 `limit`=잠재+2+노력보정×32에서 정지. 노력 보정 `grit`=(84-전체잠재 평균)/60, 0~25%. 소수점 성장은 `growthCarry`로 누적.
- 나이 배율(유효 나이 30/33/36/39에서 .8/.55/.35/.2). 노화 손실은 30세부터 시작하며 이전보다 가파르다.
- 각성 `awaken`: 34세 미만, 120타석 이상, 주요 수상 시즌에 가장 많이 훈련한 능력의 잠재 +1(능력별 최대 +6). `lastAwakening` 표시.
- 출전 `role`: 프로/마이너는 능력 점수(컨택.45/장타.25/선구.15/수비.15) 57 이하면 출전 감소(최저 30%). 고교/대학은 항상 출전.
- 타격 곡선: hitChance=.087+컨택×.0021+자신감×.00035. 리그 평균 타자는 컨택 약 75.
- 계약: 기준 상향(잔류65/단년61/이적69), 32세 이후 -1.6/년. 26세 미만은 잠재력 여유분만큼 가점(유망주 조기 방출 방지). 43세 정상급 제안 유지 테스트는 그대로 통과.
- 옛 저장: migrate가 잠재력을 생성하되 현재 능력 이상으로 보정.
- API 추가: scout, role, potentialGrade, canReroll, reroll, limit.

### UI (app.js / style.css)
- 능력치 아래 스카우트 리포트: 종합 및 능력별 등급(S/A/B/C/D), 잠재 범위(시즌이 쌓일수록 좁아짐), 한계 돌파 중 표시, 노력 보정%, 전성기(6시즌 후 공개), 각성 알림.
